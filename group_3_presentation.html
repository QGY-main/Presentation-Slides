Fact Checking
Inside Group Chats

When rumors start spreading about important things like water plants breaking down, people talk about it in chat apps first. We built JarvisClaw so users can check if a rumor is real or fake instantly without leaving the chat.

How it works — Someone pastes a suspicious claim. The bot pulls out the true facts, checks for warning signs, and gives a trust score. All from a simple !factcheck command in the chat.

Dual-Mode Architecture

Command Mode

💬

Casual Chat Mode

What the Bot Does
For Analysts

⚡

Quick Rumor Checking

When a fake Telegram post claimed a Tuas Desalination pump failed, the bot checked live utility feeds and news sources to prove it was false in under 5 seconds.

📄

Full PDF Report

For deep-dives, the bot does not just summarise text — it automatically creates a clean 6-page PDF document ready for sharing.

🔍

Inside the PDF

A simple summary of the attack, a timeline of causes and effects, and facts from trusted security groups like MITRE ATT&CK, ESET, and Dragos. It also uses classic defense ideas to explain the strategy behind the attack.
